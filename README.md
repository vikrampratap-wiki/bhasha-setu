## 📖 परिचय (Overview)

**भाषा सेतु (BhashaSetu)** एक आधुनिक, उत्तरदायी (Responsive) और उपयोगकर्ता-अनुकूल वेब उपकरण है जो दुनिया की किसी भी भाषा (अंग्रेजी, स्पेनिश, फ्रेंच, जर्मन, अरबी, रूसी, चीनी, जापानी, तमिल, तेलुगु, बंगाली, मराठी आदि) का हिन्दी में तुरंत अनुवाद करता है।

यह उपकरण विशेष रूप से वास्तविक परिस्थितियों (जैसे सम्मेलनों, बैठकों या फील्ड वर्क) को ध्यान में रखकर बनाया गया है जहाँ:
1. **इंटरनेट नहीं होता** या अस्थिर होता है (100% ऑफ़लाइन कार्य करता है)।
2. **एक साथ कई लोग बोल रहे होते हैं** (उनकी आवाजों को अलग-अलग पहचानना और स्पष्ट सुनाना)।
3. **डेटा की गोपनीयता अत्यंत महत्वपूर्ण होती है** (256-बिट एंड-टू-एंड एन्क्रिप्शन)।
4. **विभिन्न डिवाइस (टैबलेट, फोन, लैपटॉप) के बीच तात्कालिक समन्वय आवश्यक होता है** (रीयल-टाइम सिंक)।

## 🌟 प्रमुख विशेषताएं (Key Features)

### 1. 📱 सार्वभौमिक अनुकूलता (Universal Cross-Platform)
- **मोबाइल (Mobile)**: एक हाथ से उपयोग करने योग्य इंटरफ़ेस और बड़े स्पर्श बटन।
- **टैबलेट (Tablet)**: वक्ता चयन, लाइव वेवफ़ॉर्म और अनुवाद का संतुलित ग्रिड।
- **डेस्कटॉप (Desktop)**: संपूर्ण विज़ुअलाइज़र, ऑडियो एनालाइज़र और इतिहास प्रबंधन।
- **PWA (Progressive Web App)**: किसी भी ब्राउज़र से सीधे होम स्क्रीन या डेस्कटॉप पर नेटिव ऐप की तरह इंस्टॉल करने योग्य।

### 2. 🌐 किसी भी भाषा का हिन्दी में अनुवाद (Any Language to Hindi)
- **ऑफ़लाइन हाइब्रिड अनुवाद मैट्रिक्स**: 15+ प्रमुख भाषाओं के लिए अंतर्निहित शब्दकोश एवं व्याकरण संरचना।
- **देवनागरी फ़ोनेटिक ट्रांसलिट्रेटर**: नए या अपरिचित शब्दों को भी देवनागरी लिपि में सही उच्चारण के साथ प्रस्तुत करता है।
- **ऑनलाइन न्यूरल API बैकअप**: इंटरनेट उपलब्ध होने पर उच्च-स्तरीय न्यूरल अनुवाद का स्वतः उपयोग करता है।
- **कस्टम शब्दकोश**: उपयोगकर्ता अपनी विशेष शब्दावली या स्थानीय बोलियों के शब्द जोड़ सकते हैं।

### 3. 🎙️ वॉइस-टू-टेक्स्ट (Voice-to-Text / STT)
- Web Speech API के माध्यम से निरंतर उच्च-परिशुद्धता वाक् पहचान।
- बोलते समय रीयल-टाइम अंतरिम परिणाम (Interim Feedback) प्रदर्शित करता है।

### 4. 👥 बहु-वक्ता पहचान एवं विशिष्ट आवाज़ स्पष्टता (Multi-Speaker Diarization & Audio Clarity)
- **ऑडियो क्लैरिटी फ़िल्टर (Web Audio API)**:
  - 300Hz से कम की अवांछित घड़घड़ाहट (rumble) और 3400Hz से ऊपर की फुसफुसाहट को फ़िल्टर करता है।
  - भाषण फॉर्मैंट्स (2.4kHz) को +5dB बूस्ट करता है ताकि शोर-शराबे वाले वातावरण में भी हर शब्द क्रिस्टल क्लियर सुनाई दे।
- **ऑटो-पिच ($F_0$) डायराइज़ेशन**:
  - टाइम-डोमेन ऑटो-कोरिलेशन द्वारा वक्ता के स्वर-तार की फंडामेंटल फ्रीक्वेंसी मापता है और विभिन्न वक्ताओं (वक्ता 1, वक्ता 2, आदि) को अलग पहचानता है।
- **श्रव्य रूप से अलग आवाज़ में प्लेबैक (Audibly Distinct Playback)**:
  - जब हिन्दी अनुवाद सुनाया जाता है, तो प्रत्येक वक्ता के लिए भिन्न पिच (0.85x गंभीर, 1.05x सामान्य, 1.25x उच्च) और गति से आवाज़ निकलती है, जिससे सुनने वाले को स्पष्ट पता चलता है कि कौन सा व्यक्ति क्या बोल रहा है।

### 5. 🔄 रीयल-टाइम डेटा सिंक्रोनाइज़ेशन (Real-Time Sync)
- 6-अंकों के रूम कोड (Room Code) और क्यूआर/शेयर लिंक द्वारा मोबाइल, टैबलेट और लैपटॉप तुरंत आपस में सिंक हो जाते हैं।
- P2P WebRTC DataChannel और ब्रॉडकास्ट चैनल आर्किटेक्चर।

### 6. 🔒 एंड-टू-एंड एन्क्रिप्शन (E2EE)
- **AES-256-GCM** उद्योग-मानक एन्क्रिप्शन।
- **PBKDF2** (100,000 पुनरावृत्तियां SHA-256 के साथ) द्वारा रूम पासफ़्रेज़ से सुरक्षित कुंजी बनाई जाती है।
- SHA-256 विज़ुअल फ़िंगरप्रिंट द्वारा सुरक्षा का प्रत्यक्ष सत्यापन।
- अनधिकृत सर्वर या तीसरे पक्ष तक कोई भी डेटा प्लेनटेक्स्ट में नहीं पहुंचता।

## 🏗️ वास्तुकला (Architecture)

```
[ माइक्रोफ़ोन इनपुट ] 
        ↓
[ वोकल क्लैरिटी EQ & फ़िल्टर (300Hz-3.4kHz) ]
   ├──→ [ पिच विश्लेषक (वक्ता 1, 2, 3...) ]
   └──→ [ वॉइस-टू-टेक्स्ट इंजन ]
                ↓
     [ ट्रांसलेशन राउटर ]
        ├── ऑफ़लाइन मोड → स्थानीय डिक्शनरी व व्याकरण मैट्रिक्स
        └── ऑनलाइन मोड → न्यूरल अनुवाद API
                ↓
         [ हिन्दी आउटपुट ]
        ├── 🔊 बहु-पिच भिन्न आवाज़ प्लेबैक (TTS)
        ├── 🗄️ IndexedDB (सुरक्षित ऑफ़लाइन भंडारण)
        └── 🔒 AES-256-GCM एन्क्रिप्शन → 🔄 रीयल-टाइम P2P सिंक
```

## 🚀 त्वरित शुरुआत (Quick Start)

### 1. स्थानीय रूप से चलाएं (Run Locally)
किसी भी साधारण HTTP सर्वर के साथ इसे चलाया जा सकता है:

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/vikrampratap-wiki/bhasha-setu.git
cd bhasha-setu

# Node.js के माध्यम से स्थानीय सर्वर चलाएं:
npx serve .
# अथवा Python के माध्यम से:
python3 -m http.server 8080
```
ब्राउज़र में खोलें: `http://localhost:8080`

### 2. मोबाइल / टैबलेट पर इंस्टॉल करें (Install as PWA)
- क्रोम या सफारी में खोलें।
- मेनू में जाकर **"Add to Home Screen"** या **"Install App"** पर टैप करें।
- अब यह इंटरनेट बंद होने पर भी पूर्ण रूप से कार्य करेगा।

## 🔒 सुरक्षा एवं गोपनीयता (Security & Privacy)

- **ज़ीरो-नॉलेज आर्किटेक्चर**: आपका वार्तालाप किसी भी बाहरी सर्वर पर अनएन्क्रिप्टेड रूप में नहीं जाता।

- **कुंजी सत्यापन**: दोनों तरफ के उपयोगकर्ता रूम की का SHA-256 फ़िंगरप्रिंट मिलाकर सुनिश्चित कर सकते हैं कि कोई मैन-इन-द-मिडिल (MITM) नहीं है।
